# Yin-Yang v2: Rotating-Frame Spring Physics — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `v2.html` + `src/v2.js` — a yin-yang particle sphere where the classification field rotates via spring physics rather than rigid geometry, creating a fish-swimming-through-particles effect.

**Architecture:** Home positions are generated once using v1's sampling functions (yin dense, yang sparse, shadow band), stored in fixed arrays, and rotated around Z each frame. Per-particle spring physics pulls live positions toward their rotating homes; the spring lag is what makes particles appear absorbed at the fish head and released at the tail. Three particle systems (yin/yang/shadow) share the same physics loop via a `systems` array.

**Tech Stack:** Three.js 0.167.0 via CDN importmap, plain ES modules, no build step. Tests run as plain HTML files in the browser (`tests/v2-unit.html`).

**Spec:** `docs/superpowers/specs/2026-10-09-yin-yang-v2-design.md`

## Global Constraints

- Three.js version: `0.167.0` via `https://cdn.jsdelivr.net/npm/three@0.167.0/build/three.module.js`
- No build step, no npm dependencies — everything runs directly in the browser
- `index.html` and `src/main.js` must not be touched
- Spring constant `K_SPRING = 0.012`, damping `DAMPING = 0.88`, spin speed `SPIN_SPEED = 0.004`
- Hover pause: smootherstep ease-in-out over `HOVER_DURATION = 3.0` seconds
- Dot sizes: yin 1.0 × devicePixelRatio, yang 1.2 × devicePixelRatio, shadow 1.0 × devicePixelRatio

## Review Focus

1. **NaN propagation from zero-length pos vector**: if a particle reaches the origin, surface-project divides by zero → NaN infects all subsequent frames for that particle. Expected: guard `if (len < 1e-6) continue` prevents this. Test added to Task 3.
2. **Large dt on slow hardware**: `clock.getDelta()` returns wall-clock seconds; hover hoverTime uses it. If a frame takes 500ms, hoverTime jumps 0.5s. Expected: smootherstep clamps `t` to [0,1] so this is harmless.
3. **`speedAtHoverStart` captured near zero**: if the user hovers just as rotSpeed is re-accelerating from 0, `speedAtHoverStart` ≈ 0 and the pause curve barely moves. Expected: visually the sphere is nearly stopped anyway — acceptable behaviour.
4. **Shadow particles with `Math.random()`**: different runs produce different shadow layouts. Expected: the visual band is always present even with different seeds; random variation in layout is acceptable.
5. **Very high devicePixelRatio (≥ 3)**: `sizeAttenuation: false` sizes are in device pixels, so `1.0 * devicePixelRatio` on a 3× display = 3 device pixels = 1 CSS pixel. Expected: dots remain 1 CSS pixel and the pattern looks identical to a 2× display.

```javascript
// ── Yin-yang classification ────────────────────────────────────────────────
function isYin(px, py) {
  if (px * px + py * py > 1.0) return false;
  const seedR2 = 0.0324;
  if (px * px + (py - 0.5) * (py - 0.5) < seedR2) return true;
  if (px * px + (py + 0.5) * (py + 0.5) < seedR2) return false;
  if (py >= 0) {
    if (px * px + (py - 0.5) * (py - 0.5) < 0.25) return false;
    return px > 0;
  } else {
    if (px * px + (py + 0.5) * (py + 0.5) < 0.25) return true;
    return px > 0;
  }
}

// ── Fibonacci sphere sampling ──────────────────────────────────────────────
function generateParticles(numCandidates) {
  const arr = [];
  const phi = Math.PI * (3 - Math.sqrt(5));
  for (let i = 0; i < numCandidates; i++) {
    const y = 1 - (i / (numCandidates - 1)) * 2;
    const r = Math.sqrt(Math.max(0, 1 - y * y));
    const th = phi * i;
    const x = Math.cos(th) * r, z = Math.sin(th) * r;
    if (isYin(x, y)) arr.push(x, y, z);
  }
  return new Float32Array(arr);
}

function generateYangParticles(numCandidates) {
  const arr = [];
  const phi = Math.PI * (3 - Math.sqrt(5));
  for (let i = 0; i < numCandidates; i++) {
    const y = 1 - (i / (numCandidates - 1)) * 2;
    const r = Math.sqrt(Math.max(0, 1 - y * y));
    const th = phi * i;
    const x = Math.cos(th) * r, z = Math.sin(th) * r;
    if (!isYin(x, y)) arr.push(x, y, z);
  }
  return new Float32Array(arr);
}

function nearestYinDist(px, py, maxDist) {
  let best = maxDist + 1;
  for (let i = 0; i < 8; i++) {
    const angle = (i / 8) * Math.PI * 2;
    const dx = Math.cos(angle), dy = Math.sin(angle);
    if (!isYin(px + dx * maxDist, py + dy * maxDist)) continue;
    let lo = 0, hi = maxDist;
    for (let k = 0; k < 8; k++) {
      const mid = (lo + hi) / 2;
      if (isYin(px + dx * mid, py + dy * mid)) hi = mid; else lo = mid;
    }
    best = Math.min(best, (lo + hi) / 2);
  }
  return best;
}

function generateShadowParticles(numCandidates, bandWidth) {
  const arr = [];
  const phi = Math.PI * (3 - Math.sqrt(5));
  for (let i = 0; i < numCandidates; i++) {
    const y = 1 - (i / (numCandidates - 1)) * 2;
    const r = Math.sqrt(Math.max(0, 1 - y * y));
    const th = phi * i;
    const x = Math.cos(th) * r, z = Math.sin(th) * r;
    if (isYin(x, y)) continue;
    const d = nearestYinDist(x, y, bandWidth);
    if (d > bandWidth) continue;
    const t = 1 - d / bandWidth;
    if (Math.random() < t * t * t * t) arr.push(x, y, z);
  }
  return new Float32Array(arr);
}

// ── Generate home positions ────────────────────────────────────────────────
const yinHome    = generateParticles(120000);
const yangHome   = generateYangParticles(1800);
const shadowHome = generateShadowParticles(80000, 0.2);

// Live positions start equal to homes; velocities start at zero
const yinPos    = new Float32Array(yinHome);
const yangPos   = new Float32Array(yangHome);
const shadowPos = new Float32Array(shadowHome);
const yinVel    = new Float32Array(yinHome.length);
const yangVel   = new Float32Array(yangHome.length);
const shadowVel = new Float32Array(shadowHome.length);

// ── Sprite texture ─────────────────────────────────────────────────────────
function makeCircleTexture(r, g, b) {
  const sz = 64;
  const c = document.createElement('canvas');
  c.width = sz; c.height = sz;
  const ctx = c.getContext('2d');
  const grad = ctx.createRadialGradient(sz/2, sz/2, 0, sz/2, sz/2, sz/2);
  grad.addColorStop(0,   `rgba(${r},${g},${b},1)`);
  grad.addColorStop(0.5, `rgba(${r},${g},${b},0.9)`);
  grad.addColorStop(1,   `rgba(${r},${g},${b},0)`);
  ctx.fillStyle = grad;
  ctx.fillRect(0, 0, sz, sz);
  return new THREE.CanvasTexture(c);
}

// ── BufferGeometry for each system ─────────────────────────────────────────
const yinGeo = new THREE.BufferGeometry();
yinGeo.setAttribute('position', new THREE.BufferAttribute(yinPos, 3));

const yangGeo = new THREE.BufferGeometry();
yangGeo.setAttribute('position', new THREE.BufferAttribute(yangPos, 3));

const shadowGeo = new THREE.BufferGeometry();
shadowGeo.setAttribute('position', new THREE.BufferAttribute(shadowPos, 3));
```

```javascript
// ── Physics constants ──────────────────────────────────────────────────────
const K_SPRING   = 0.012;
const DAMPING    = 0.88;
const SPIN_SPEED = 0.004;

// ── Physics step ───────────────────────────────────────────────────────────
function physicsStep(sys, theta) {
  const cosT = Math.cos(theta);
  const sinT = Math.sin(theta);
  for (const { pos, home, vel, geo } of sys) {
    const N = pos.length / 3;
    for (let i = 0; i < N; i++) {
      const i3 = i * 3;
      // Rotate home around Z by theta
      const hx = home[i3]     * cosT - home[i3 + 1] * sinT;
      const hy = home[i3]     * sinT + home[i3 + 1] * cosT;
      const hz = home[i3 + 2];
      // Spring toward rotated home
      vel[i3]     += K_SPRING * (hx - pos[i3]);
      vel[i3 + 1] += K_SPRING * (hy - pos[i3 + 1]);
      vel[i3 + 2] += K_SPRING * (hz - pos[i3 + 2]);
      // Tangent project: remove radial component from vel
      const radial = vel[i3] * pos[i3] + vel[i3 + 1] * pos[i3 + 1] + vel[i3 + 2] * pos[i3 + 2];
      vel[i3]     -= radial * pos[i3];
      vel[i3 + 1] -= radial * pos[i3 + 1];
      vel[i3 + 2] -= radial * pos[i3 + 2];
      // Integrate
      pos[i3]     += vel[i3];
      pos[i3 + 1] += vel[i3 + 1];
      pos[i3 + 2] += vel[i3 + 2];
      // Surface project (normalize, guard against zero-length)
      const len = Math.sqrt(pos[i3] * pos[i3] + pos[i3 + 1] * pos[i3 + 1] + pos[i3 + 2] * pos[i3 + 2]);
      if (len < 1e-6) continue;
      pos[i3]     /= len;
      pos[i3 + 1] /= len;
      pos[i3 + 2] /= len;
      // Damping
      vel[i3]     *= DAMPING;
      vel[i3 + 1] *= DAMPING;
      vel[i3 + 2] *= DAMPING;
    }
    geo.attributes.position.needsUpdate = true;
  }
}

// ── Animation loop (theta accumulates at SPIN_SPEED; Task 4 adds hover) ───
let theta = 0;

function animate() {
  requestAnimationFrame(animate);
  theta += SPIN_SPEED;
  physicsStep(systems, theta);
  renderer.render(scene, camera);
}

animate();
```

```javascript
// ── Hover-to-pause (smootherstep, 3s) ─────────────────────────────────────
function smootherstep(t) {
  t = Math.max(0, Math.min(1, t));
  return t * t * t * (t * (t * 6 - 15) + 10);
}

const HOVER_DURATION = 3.0;
let rotSpeed         = SPIN_SPEED;
let hovering         = false;
let wasHovering      = false;
let hoverTime        = 0;
let speedAtHoverStart = SPIN_SPEED;

const raycaster = new THREE.Raycaster();
const mouse     = new THREE.Vector2();
const clock     = new THREE.Clock();

// ── Drag rotation ──────────────────────────────────────────────────────────
let dragging = false, lastX = null, lastY = null;

renderer.domElement.addEventListener('mousedown', e => {
  dragging = true;
  lastX = e.clientX;
  lastY = e.clientY;
});

window.addEventListener('mouseup', () => { dragging = false; });

window.addEventListener('mousemove', e => {
  mouse.x =  (e.clientX / window.innerWidth)  * 2 - 1;
  mouse.y = -(e.clientY / window.innerHeight) * 2 + 1;
  raycaster.setFromCamera(mouse, camera);
  hovering = raycaster.intersectObject(innerSphere).length > 0;

  if (!dragging) return;
  const dx = e.clientX - lastX;
  const dy = e.clientY - lastY;
  lastX = e.clientX;
  lastY = e.clientY;
  group.rotation.y += dx * 0.01;
  group.rotation.x += dy * 0.01;
});
```

```javascript
    rotSpeed += (SPIN_SPEED - rotSpeed) * 0.025;
  }
  wasHovering = hovering;

  theta += rotSpeed;
```
